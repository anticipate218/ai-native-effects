## 主要参数

| 属性 | 默认值 | 说明 |
| --- | --- | --- |
| `color` | `#7c5cff` | 主色 |
| `accent` | `#5ef2ff` | 辅色 |
| `size` | `240px` | 尺寸 |
| `speed` | `1` | 速度倍率 |
| `motion` | `auto` | 跟随系统「减少动态效果」设置 |
