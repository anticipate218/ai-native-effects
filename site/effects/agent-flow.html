Agent Flow Visualizer

Agent runs are usually shown as a scrolling log. This component turns the same events into a flow graph that grows as the agent works: the plan, parallel tool calls, joins and the final answer. Running steps glow, edges carry data, finished steps show their duration, and any step expands to show its result.

API

Methods

MemberDescription
addStep(step)Adds a step: { id, parents?, kind?, title, detail?, output?, status?, duration? }. Returns false for a duplicate id.
updateStep(id, patch)Updates any field; durations are measured automatically between running and done.
removeStep(id), reset()Removes one step (and its edges) or the whole run.
toggleStep(id, open?)Expands or collapses a step's details.
stepsGet a snapshot, or assign an array: it is diffed, so existing cards are kept and animated (ideal for React/Vue state).
stackedtrue while the single-column layout is in use.

FieldValuesDescription
