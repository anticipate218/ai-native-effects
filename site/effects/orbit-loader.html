Orbit Data Loader

A loader for the slow parts of AI and geo products: downloading imagery, indexing a corpus, syncing a dataset. Satellites downlink data packets to a procedural planet while the ring fills, so a long wait looks like work in progress instead of a frozen spinner.

API

Attributes

AttributeValuesDefaultDescription
progress0–1 or 0%–100%noneDownload progress. Omit it for an indeterminate loader. Reaching 1 plays the completion pulse.
satellites1–63Number of orbiting satellites.
errorbooleanoffFailed state: the ring and satellites turn to the danger color and downlinks stop.
show-valuebooleanoffShows the percentage over the planet.
colorany CSS color#7c5cffPlanet color: ocean, land, graticule and ring track are derived from it.
accentany CSS color#5ef2ffSatellites, downlinks and the progress arc.
sizeCSS length240pxWidth and height.
speed0–51Animation time scale. 0 freezes the scene.
motionauto reduce fullautoauto follows prefers-reduced-motion.
labelstringLoading dataAccessible name of the progress bar.
seedinteger7Seed for the planet's continents and the orbits.

Properties and events

MemberDescription
progressnumber | null. Set null for indeterminate (reflects to the attribute).
error, satellitesReflect to their attributes.
ane-completeFired once each time progress reaches 100%. Bubbles and crosses shadow roots.

PropertyDescription
