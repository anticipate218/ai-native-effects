AI Thinking Buddy

A tiny robot that makes agent status readable at a glance. Each state gets its own body language and badge, so users can tell thinking from waiting on a tool from done without reading a word.

API

Attributes

AttributeValuesDefaultDescription
stateidle thinking waiting success erroridleWhat the agent is doing. Each change plays a short entry reaction.
colorany CSS color#7c5cffBody color; highlights and shading are derived from it.
accentany CSS color#5ef2ffEyes, mouth and idle/thinking glow.
sizeCSS length160pxWidth and height. Plain CSS width works too.
speed0–51Animation time scale. 0 freezes the buddy.
motionauto reduce fullautoauto follows prefers-reduced-motion.
interactivebooleanoffEyes follow the pointer; tapping gives a happy bounce.
announcebooleanoffAnnounces state changes through a polite live region.
labelstringper stateOverrides the accessible label.
seedinteger7Seed for blinks, glances and confetti (reproducible recordings).

Properties, methods and events

MemberDescription
stateGet or set the state (reflects to the attribute).
labelsPer-state accessible labels for localisation, e.g. { thinking: '正在思考' }.
replay()Replays the current state's entry animation (jump and confetti, head shake…).
boop()Plays the happy bounce.
ane-statechangeEvent fired on every state change. event.detail = { state, previous }; bubbles and crosses shadow roots.

CSS custom properties

PropertyDescription
--ane-sizeWidth and height (default 160px).
--ane-buddy-color, --ane-buddy-accentTheme colors; the attributes take precedence.
--ane-success, --ane-warning, --ane-dangerStatus colors shared by all effects.
