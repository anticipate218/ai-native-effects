Token Stream Text

Streamed answers arrive in uneven bursts, so raw output stutters and jumps. This component buffers the chunks, releases words at an adaptive pace and lets each one rise out of a blur and dry from the accent color behind a glowing caret. Real, selectable text; English and CJK alike.

Methods, properties and events

MemberDescription
write(text)Adds a chunk. Half-arrived words and unclosed `code` wait for the next chunk.
done()Marks the end of the source; the rest is revealed, then ane-stream-end fires.
stream(source)Consumes an async iterable or a ReadableStream of strings or bytes, then calls done(). Resolves when fully revealed.
skip(), reset()Reveal everything now / clear for a new answer.
text, streaming, finishedReceived text, whether the stream is still open, and a promise for the end.
ane-stream-endFired once per stream. event.detail = { text }; bubbles and crosses shadow roots.
FormattingLine breaks, blank-line paragraphs, `inline code` and **bold**.
