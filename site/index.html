Effects

Each effect is a dependency-free Web Component. Use it from React, Vue, Svelte, Angular or plain HTML.

Built for real products

Every effect ships with the same guarantees.

Framework-agnostic

Standard Custom Elements with attributes, properties and DOM events. Safe to import during SSR.

Accessible

Meaningful ARIA labels, optional live announcements, and a calm variant for prefers-reduced-motion.

Light on the main thread

Zero dependencies, one shared animation loop, and effects pause automatically when off-screen.

Tunable

Colors, speed and size via attributes or CSS custom properties. Theme it to match your product.
